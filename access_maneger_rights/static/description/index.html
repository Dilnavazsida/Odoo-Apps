Access Rights Manager - Hide Menu, Field & Button

Complete User Access Control for Odoo — Without Coding

Access Rights Manager helps you manage who can see and do what inside Odoo. Create simple rules, assign users and companies, then control menus, models, fields, buttons, tabs, filters, group by, reports, actions, domains and chatter — all from one centralized app.

Perfect for businesses that need role-based restrictions for sales, warehouse, accounts or support teams, without creating complex security groups or writing XML / Python code.

Why this app?
Native Odoo access rights are powerful but technical. This app gives admins a clear UI to apply day-to-day restrictions quickly and safely.
Who is it for?
Odoo admins, implementation partners and companies that need per-user visibility control across Sales, Inventory, Accounting and more.
What you get
Global flags, menu/field/button/tab hiding, filter & group-by control, domain-based record limits, chatter control and multi-company support.

Features

Global Read-Only, Disable Import/Export/Delete/Archive, Hide Chatter, Disable Developer Mode.
Hide any menu or sub-menu for selected users.
Model access: Create, Edit, Delete, Duplicate, Import, Export, Archive + hide Reports & Actions.
Field access: Invisible, Read-Only, Required, Remove External Link.
Hide Buttons and Tabs/Pages with auto suggestions from views.
Hide Filters and Group By options from the search panel.
Domain / record access so users only see relevant records.
Hide Chatter globally or per model. Multi-company rules supported.

Install the module from Apps

Search “Access Rights Manager” and click Activate.

Enable Access Rights Manager on the user

Settings → Users → Extra Rights → check Access Rights Manager.

Open Access Rights Manager from the home apps

Read-Only Global Access

Configure read-only rules so selected users can view records but cannot create or edit them.

Configuration: enable Read-Only on the rule
After: New / create actions are removed for that user

Disable Export Global

Prevent selected users from exporting records from list views.

Before: Export is available in Actions
Configuration: enable Disable Export
After: Export is removed from Actions

Selected users no longer see Export in the Actions menu.

Disable Import Global

Hide import options so users cannot upload external data into the system.

Before: Import records is available
Configuration: enable Disable Import
After: Import records is hidden from the settings menu

Users can no longer import records from the list view settings menu.

Disable Archive / Unarchive Global

Remove Archive and Unarchive from the Actions menu for selected users.

Before: Archive / Unarchive are available
Configuration: enable Disable Archive/Unarchive
After: Archive / Unarchive are removed from Actions

Disable Delete Global

Hide delete so users cannot remove records from list or form actions.

Before: Delete is available in Actions
Before (Sales): Delete is available in Actions
Configuration: enable Disable Delete
After: Delete is no longer shown in Actions

Hide Chatter Global

Remove the chatter panel from forms for selected users.

Before: Chatter is visible on the form
Configuration: enable Hide Chatter
After: Chatter panel is hidden

Disable Developer (Debug) Mode

Restrict developer / debug mode so users cannot inspect technical field metadata.

Before: Debug field info is available
Configuration: enable Disable Developer Mode
After: Developer / debug field info is blocked

Affected users no longer get technical field tooltips or developer mode access.

Hide Menu & Sub-menu

Hide specific menus or submenus so users only see what they need.

Before: Quotations and Orders menus are visible
Configuration: add menus under Hide Menu
After: hidden menus no longer appear in navigation

Hide Model Reports

Control visibility of model-specific print reports (PDF Quote, Quotation / Order, etc.).

Before: Print reports are visible
Configuration: select reports under Hide Reports
After: Print reports are removed from the menu

Hide Model Actions

Hide specific server / contextual actions (Send email, Share, etc.) for selected users.

Before: actions are visible in the cog menu
Configuration: select actions under Hide Actions
After: selected actions are hidden

Model Access Management

Per model: hide create, edit, delete, duplicate, import, export, archive, plus reports and actions.

Before: New, Export and Delete are available
Configuration: Hide Create / Delete / Export on Sales Order
After: restricted actions are removed for that model

Field Access Rights

Make fields invisible, read-only, or required. Protect sensitive data on forms and lists.

Before: fields such as Payment Terms and Quotation Template are visible
Configuration: set fields Invisible under Field Access
After: selected fields are hidden from the user

Button / Tab / Page Access

Show or hide form buttons and notebook tabs based on the user rule.

Before: Confirm button and Other Info tab are visible
Configuration: hide Confirm button and Other Info tab
After: button and tab are removed for that user

Filter / Group By Access

Hide specific search filters and group-by options from the search panel.

Before: Order Date filter and Group By options are visible
Configuration: select filters and group-by to hide
After: selected filters / group-by options are gone

Filter Domain Access Control

Limit which records users can see using a domain. Preview shows how many records match.

Before: user sees all statuses in the list
Configuration: domain Status = Quotation with record preview
After: user only sees matching records (e.g. Quotations)

Chatter Model Access Control

Hide chatter only on selected models (instead of globally).

Before: Chatter is visible on Sales Order
Configuration: Hide Chatter for Sales Order model
After: Chatter is hidden on that model
What does this module do?
It manages menus, models, fields, buttons, tabs, filters, domains and chatter access for selected users without coding.
Can one rule apply to multiple users?
Yes. Add multiple users on the rule; all receive the same restrictions.
Different from Odoo built-in rights?
Native groups mainly cover model ACL. This app adds UI-level and domain-level control from one form.
Multi-company support?
Yes. Set Companies on the rule to scope restrictions.
Filter/Group By not hiding?
Ensure Users are set, select the exact filter name, then logout/login the affected user.
Which Odoo versions?
Odoo 19.0, 18.0, 17.0, Community, Enterprise and Odoo.sh.
